## Things that do not travel with the repo

Claude's memory notes live in `~/.claude/projects/.../memory/` on the
Windows machine. The lessons that matter most, in one line each:

- Verify the claim on the live page, not that the code does what was meant.
- Green tests prove a component works, never that anything calls it.
- A grep piped through `head` is not a search; read every importer before deleting.
- Join records on the identity they are graded by, never on rank or position.
- Probability before price; cross-book line shopping is out.
- CI runs `python -m unittest discover` on stdlib only; pytest-style files
  need `tests/_unittest_bridge.py`.
- No build step in `web/`: one missing ES module blanks the whole app
  (`tests/test_web_imports_resolve.py` guards it).
