# Brand Naming Sprint — 2026-09-01

Access date for every finding below: 2026-09-01. **This is a fast collision/knockout
screen, not legal clearance.** No purchase, filing, incorporation, or handle-claim
should happen on any name here before trademark counsel and Brey sign-off.
Method for every check is stated inline; anything that could not be conclusively
checked is marked CANNOT VERIFY, never guessed.

Methodology reused from `docs/BRAND_SCREEN_LINEHOUND.md`:
- **Domain**: DNS resolve (`getent hosts`) to establish registered/unregistered,
  then an HTTP(S) fetch to see status/content. No WHOIS, no registrar account,
  no purchase.
- **Search collision**: web search for `"<name>" betting/sports app`.
- **App store**: web search for the name plus iOS App Store / Google Play.
- **USPTO TESS**: attempted directly; as with the LINEHOUND screen, tmsearch.uspto.gov
  could not be queried live from this environment. This is a **knockout screen
  gap, not a clearance opinion** — every trademark verdict below is search-engine
  evidence only.
- **Social handles**: not exhaustively re-run per candidate this round (budget) —
  flagged CANNOT VERIFY where relevant; treat as unverified for all 12.

## Part 4 — Genuine survivors (4)

**1. Steamline** — the strongest candidate on this list. "Steam" is core
sharp-bettor vocabulary (a line moving fast on sharp money), which makes the
name bettor-native in a way LINEHOUND (a generic hunting-dog compound) is not.
It cleared every check with no collision found anywhere — no domain squatter,
no betting-app match, no search-result noise. Where it beats LINEHOUND: zero
real-world collision was found at all (LINEHOUND still carries the Line Hound
Tackle LLC collision and an unresolved, unverifiable .com). Where it's weaker:
it is untested with real bettors — "steam" is insider jargon, and a portion of
the target audience (casual/newer bettors, which the product also serves) may
not immediately parse it without an explainer, versus LINEHOUND's more
transparent "something is hunting down a line for you" metaphor.

**2. Wirecheck** — good sports-broadcast tone ("on the wire" = the live odds
feed) paired with the product's actual verb (checking a bet). It beats
LINEHOUND on the trademark/business axis: the one existing collision is a
parked-for-sale domain (HugeDomains), not an active company with a real trademark
interest, versus LINEHOUND's unresolved .com and small-but-real Line Hound Tackle
LLC. It is weaker than LINEHOUND on the "hunting/checking" narrative device the
prior design work is already partly built around, and the .com would need to be
purchased rather than simply claimed.

**3. Slipwatch** — direct bettor-native language (the bet slip is the actual
artifact a bettor holds) combined with an honest, watchful verb that matches
the product's positioning ("we publish our losses," "we watch the price").
It beats LINEHOUND by having a completely clean domain (NXDOMAIN, unregistered)
and no betting-category app match. It's weaker on distinctiveness — "watch" is
a common suffix across this whole naming exercise (Bookwatch, Linewatch,
Steamwatch all use it), so this and its siblings compete with each other more
than with the baseline.

**4. Bookwatch — survivor with a real caveat.** "The book" is the sportsbook
itself, so "watching the book" is an unusually precise, plain-English
description of exactly what the product does — arguably the most bettor-native
name on the list. It beats LINEHOUND conceptually. But the .com and the exact
app-store search term are both already owned by an active, unrelated
book-summary video company with its own iOS/Android apps — meaning a bettor
searching "Bookwatch app" today lands on someone else's product, a sharper
practical problem than LINEHOUND's ambiguous 503/000 domain. Recommend this
one only if Brey is comfortable with a non-.com domain strategy and accepts
some app-store search dilution.

**Not a survivor, but worth naming to Brey directly: Filmroom and Huddlecheck**
both score very high on sports-game feel (arguably higher than anything else
on the list, including LINEHOUND) but each sits close to a real, if
non-competing, existing use ("Film Room" sports-betting-regulation content and
video-scouting tools; "Huddle" as a B2B odds/microbetting infrastructure
vendor). Neither is a KILL, both are CAUTION — worth a second look after
counsel input rather than dropped outright.

## Part 5 — Explicit KILLs (do not carry forward)

- **Sharpline** — direct, same-category, same-name collision with an active
  70,000-member sports-betting-picks Discord/brand (SharpLine Sports) and a
  second, separately-branded SharpLine sports-betting app. This is not a soft
  caution; it's the clearest KILL in the set.
- **Devig** — real genericness risk. Multiple existing tools already use
  "devig"/"de-vig" as the generic name for exactly the calculation our product
  performs. A brand built on a generic term invites weak/no trademark
  protection and permanent confusion with "a devig calculator" as a category
  of feature, not a company name.
- **Coverline** — leaning KILL. Phonetically and conceptually close to
  "Covers" (Covers.com / Covers app), a 30-year incumbent occupying the
  identical scores/picks/odds category. Likelihood-of-confusion risk with a
  major existing player is the highest of any candidate that isn't an exact
  string match.
- **Coverage Grid** (prior finalist, re-flagged) — same shape of problem as
  Coverline: "SportsGrid" is a real, app-store-present incumbent in the exact
  category, sharing the "-Grid" root. Not previously surfaced this clearly;
  worth a second look before treating it as a live finalist.

document authorizes a domain purchase, a trademark filing, a handle claim, or
