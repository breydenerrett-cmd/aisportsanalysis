# LineHound outreach scripts

Honest-only rules for every script below:
- Never claim profit, edge, or a win rate. Say "no edge is claimed".
- State plainly that the current public MLB record is negative. Before each send, open the record page and copy the live number into `[MLB_RECORD]` (for example "X-Y, N units"). Do not use a stale number.
- Replace `[RECORD_URL]` with the public record page. Do not put the link in a cold first message; offer it.
- You send every message by hand from your own account. No tools, no scripts, no bulk. Edit the first line for each target (targets.csv has a specific `first_line` for each row).
- Never mention Bet Check, by name or by description (owner ruling, 2026-09-22). "Compares prices across books" means the Odds view only.
- "The MLB record is negative" means the current rule's counted picks. The previous rule's record is shown beside it on the record page; do not quote the better one alone.
- Disclose that you built it. 21+, bet responsibly. No sportsbook or casino referral links.
- Rule status for each channel is in channels.md. Reddit rules were not read first-hand: read each sub's rules yourself before posting.

Offers being tested:
1. Individual: $19.99/month, 7-day free trial.
2. Discord community feed: posts the card and the public record into one channel automatically. 7 days free, then $149/month per server.

## (a) Discord DM to a server owner (three variants, each under 60 words, each ends with one yes/no question)

**Variant A, direct trial offer (53 words)**
> Hi [Name], I'm Brey. I publish a nightly MLB/NFL card before the game and grade it in public, losses included (MLB record is currently negative). No edge claimed. I made a bot that posts it in one channel of your server. Is it okay if I send you a 7-day free trial link?

**Variant B, feedback first (47 words)**
> Hi [Name], quick one. I run a public, hash-chained record of nightly MLB/NFL cards (every loss visible, nothing editable). I'm not claiming an edge. Before I ever pitch anything: would you be willing to look at the record page and tell me what looks fake or confusing?

**Variant C, permission first (45 words)**
> Hi [Name], I have a Discord feed that posts a nightly MLB/NFL card and its public record (losses included, no edge claimed) into one channel. Free for 7 days, then $149/month per server. Before I send details: does [Server] allow outside bots in its channels?

Use: open with the specific `first_line` from targets.csv in place of the first sentence when it fits the 60-word cap, or send the first line as message one and the variant as message two only after they reply. Variant B is the safest first touch for small owner-led servers. Variant C fits servers that have a bot or ticket policy. Variant A fits servers that already post picks.
