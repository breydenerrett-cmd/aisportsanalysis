## 2. Production app on Fly (one-time, from your own Fly session)

Follow `deploy/DEPLOY_RUNBOOK.md` "production promotion", which is:

```bash
fly apps create linehound-prod
fly volumes create app_data --app linehound-prod --region iad --size 1
```

Then the repository secret `FLY_PROD_API_TOKEN` (Settings -> Secrets and
variables -> Actions); `deploy-prod.yml` refuses to run without it.

Memory: `deploy/fly.production.toml:110` sets 512 MB. The streaming fix
(`4521080e`) took the startup peak from 1,471 MB to a measured 540 MB and
staging deployed green on it (run 36495100095, every page 200). 512 MB is
under that peak: set `memory_mb = 1024` in `deploy/fly.production.toml`
before the first production deploy (your call on the small extra Fly
cost; I have not changed the file).

## 3. Billing secrets (all four, or nothing sells)

From `deploy/DEPLOY_RUNBOOK.md` step 1e and `deploy/secrets.md`:

```bash
fly secrets set --app linehound-prod \
  APP_ADMIN_TOKEN=<long random> \
  BILLING_PROVIDER=stripe \
  STRIPE_API_KEY=<live secret key> \
  STRIPE_WEBHOOK_SECRET=<signing secret of the endpoint below> \
  STRIPE_BETA_PRICE_ID=<price id of the $19.99/month plan>
```

In Stripe: a product with a recurring $19.99/month price (the code's
`BETA_PLAN_PRICE_CENTS = 1999`, `src/appstate/billing.py:94`); a webhook
endpoint `https://linehound.app/billing/webhook` (`api/billing.py:285`)
subscribed to `checkout.session.completed`, `customer.subscription.created`,
`customer.subscription.updated`, `customer.subscription.deleted`
(`src/appstate/billing.py:917-944`). The trial length comes from
`STRIPE_TRIAL_DAYS` (default in `trial_period_days()`, `billing.py:129`);
the landing copy says 7 days, so set 7.

Partial configuration fails quietly: with `STRIPE_API_KEY` but no
`BILLING_PROVIDER=stripe`, every buyer is waitlisted (runbook lines 59-74).

## 4. DNS and certificate
