# Naming — Candidates and Screening

Date: 2026-08-31. Companion to BRAND_RESEARCH.md (Parts 1 and 4). Research-only — no logos, no colors, no design decisions made here.

**IMPORTANT DISCLAIMER: This is not trademark clearance.** Every check below is a public, informal, same-day look at whether a name is obviously already spoken for (a resolving domain, an obvious existing betting/sports product, an App Store collision). A real trademark search — full USPTO/state/common-law search, class-specific, run by a trademark attorney — is required before any name is adopted. Nothing here should be read as "cleared."
